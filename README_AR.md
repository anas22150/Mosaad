# خبير AI — نسخة جاهزة للرفع على GitHub

## بناء APK تلقائيًا
1. ارفع **كل محتويات هذا المجلد** إلى مستودع GitHub جديد، وتأكد أن مجلد `.github` موجود.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build Khabeer AI APK** ثم اضغط **Run workflow**. ويمكن أن يبدأ البناء تلقائيًا بعد رفع الملفات إلى فرع `main` أو `master`.
4. انتظر انتهاء المهمة وظهور علامة نجاح خضراء.
5. افتح تشغيل البناء الناجح، وانزل إلى **Artifacts**، ثم نزّل `Khabeer-AI-APK.zip`. فك ضغطه لتحصل على ملف APK.

إذا فشل البناء، افتح المهمة الحمراء وانسخ آخر 30–50 سطرًا من سجل الخطأ وأرسلها للمساعدة في إصلاح السبب.

## مكونات المشروع
- `mobile/`: تطبيق Flet عربي RTL، مع شعار SVG مضمّن داخل الكود.
- `server/`: خادم FastAPI للاتصال بخدمة Claude.
- `.github/workflows/build-apk.yml`: إعداد البناء التلقائي على GitHub Actions.

## إعداد خادم الذكاء الاصطناعي
التطبيق يحتاج خادمًا منشورًا على HTTPS. أضف مفتاح Anthropic بنفسك إلى Secrets/Environment Variables في استضافة الخادم بالاسم `ANTHROPIC_API_KEY`، ولا تضع المفتاح داخل GitHub repository أو التطبيق أو المحادثة. بعد نشر الخادم، ضع عنوانه في حقل «رابط الخادم المنشور» داخل التطبيق.

## حدود النسخة الحالية
المتاح حاليًا: الأسئلة النصية وإنشاء امتحان من نص درس بعد إعداد الخادم ومفتاح API.
لم يُنفّذ بعد: استخراج محتوى الصور وPDF وWord، وتصدير الامتحان إلى PDF، والحسابات وقاعدة البيانات وبنك الأسئلة الدائم.
